# 🎓 CampusConnect – Placement Management System

**CampusConnect** is a web-based Placement Management System designed to simplify and streamline the campus recruitment process by connecting **students, recruiters, and placement officers** on a single platform.

## 🚀 Project Overview

CampusConnect helps students discover job opportunities, check eligibility, apply for placement drives, and track their application status. Placement officers can manage student details, recruiters, job drives, and placement activities efficiently.

The system provides a centralized and user-friendly platform for managing the complete placement workflow.

## ✨ Key Features

* 👨‍🎓 Student Registration and Login
* 📝 Student Profile and Resume Management
* 💼 Job and Placement Drive Listings
* 🔍 Job Search and Filtering
* ✅ Eligibility Checking
* 📩 Online Job Applications
* 📊 Application Status Tracking
* 🏢 Recruiter and Company Management
* 🔔 Placement Notifications
* 📈 Placement Statistics and Reports
* 🔐 Secure User Authentication
* 📱 Responsive and User-Friendly Interface

## 👥 User Roles

### 👨‍🎓 Student

* Create an account
* Manage profile
* Upload resume
* View available jobs
* Check eligibility
* Apply for jobs
* Track application status

### 🧑‍💼 Placement Officer / Admin

* Manage student records
* Manage recruiters and companies
* Create and manage placement drives
* Monitor applications
* Track placement statistics
* Generate reports

### 🏢 Recruiter

* Manage company information
* Post job opportunities
* View eligible candidates
* Manage recruitment activities

## 🎯 Objective

The main objective of CampusConnect is to **digitize and simplify the campus placement process**, reduce manual work, improve communication between students and recruiters, and provide an organized platform for managing placement activities.
